# ISO/IEC 9899:2018 (C17) Conformance Test Suite for `slimcc-pir` + `pirc`

A self-contained, strict ISO C17 conformance test suite designed to exercise `slimcc-pir` (frontend + PIR HIR emitter) and `pirc` (verifier, progressive lowering, SSA optimizer, register allocator, and native backend), inspired by the ACVC 1.11 architecture (`tests/acvc83/`).

Every test is validated against a strict ISO C17 reference compiler (`clang -std=c17 -pedantic-errors`). Optional C17 features (`_Complex` via `__STDC_NO_COMPLEX__`, `<threads.h>` via `__STDC_NO_THREADS__`) are cleanly gated as `NOT-APPLICABLE` per ISO C17 §6.10.8.3, while C17 `_Atomic` / `<stdatomic.h>` and `_Thread_local` are thoroughly tested including multi-threaded `pthread` stress tests.

## Usage

```sh
# Run the full C17 suite on slimcc-pir + pirc at -O2 with PIR HIR verification
python3 tests/c17_conformance/run_c17.py --opt O2 --verify-pir --verbose

# Run across all optimization levels (-O0, -O1, -O2)
python3 tests/c17_conformance/run_c17.py --opt all --verbose

# Validate the suite itself against host clang (-std=c17 -pedantic-errors)
python3 tests/c17_conformance/run_c17.py --compiler clang --opt O2 --verbose

# Filter by class, section, or regex
python3 tests/c17_conformance/run_c17.py --classes c,l --filter "atomic|tls" --opt all --verbose
```
